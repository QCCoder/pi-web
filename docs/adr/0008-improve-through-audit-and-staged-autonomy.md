# Improve through audit and staged autonomy

Feedback Loops begin at L1 report-only and improve through Loop Audits of real Run evidence; people approve changes and promotion to L2 assisted or L3 unattended authority, while incidents, false positives, or cost spikes can demote or pause a Loop. We deliberately exclude automatic per-Round self-rewriting in v0 because unreviewed changes would turn noisy evidence into prompt drift and make regressions difficult to attribute or reverse.
